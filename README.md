# Olive Clone

A Next.js clone of [oliveapp.com](https://www.oliveapp.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- [Next.js 14](https://nextjs.org/) — App Router
- Plain CSS Modules
- Google Fonts (DM Sans, DM Serif Display)

## Pages

- `/` — Hero section + How It Works

## Components

- `Navbar` — sticky nav with dropdowns and mobile menu
- `Hero` — animated phone mockup with product carousel
- `HowItWorks` — 3-card section with scroll animations
