# Olive Clone

A Next.js clone of [oliveapp.com](https://www.oliveapp.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- [Next.js 14](https://nextjs.org/) — App Router
- Plain CSS Modules
- Google Fonts (DM Sans, DM Serif Display)
